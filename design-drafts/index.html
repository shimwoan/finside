룰루랩·엔터테이크 등 국내 뷰티테크 기업 벤치마킹 기반. 클릭해서 실제 사이트 헤더/푸터와 함께 렌더링된 모습을 확인하세요.

  • Template A — Card Grid 4개 카드를 항상 모두 노출 (탭 없음). 룰루랩·엔터테이크의 기본형 패턴. 장점: 한눈에 전체 사업영역 파악, 클릭 한 번으로 상세 이동 / 단점: 설명 텍스트가 짧아짐
  • Template B — Trust Stats + Card Grid 카드 그리드 위에 신뢰 지표(TRL, 파트너 수 등) 스트립 추가. 룰루랩의 수치 강조 패턴. 장점: B2B 설득력 강화 / 단점: 섹션이 더 길어짐
  • Template C — Compact Pill Tabs (현재 구조 개선안) 기존 탭-스위처 유지, 다만 좌측 세로 탭 대신 상단 알약형 탭으로 축소. 4개 탭이 항상 한 줄에 다 보임. 장점: 기존 코드/데이터 구조 재사용 용이, 상세 설명 유지 / 단점: 사업영역 전체를 한눈에 비교하긴 어려움

  • Template D — Visual Roadmap & Comparison 비교 표를 막대형 리스트로, 매출 로드맵을 연결된 성장 막대 타임라인으로 시각화. 투자자·B2B 대상 스캔 가독성에 집중. 장점: 숫자가 한눈에 들어옴, 스토리텔링 강화 / 단점: 정확한 수치 비교엔 표보다 불리할 수 있음
  • Template E — Sticky Side-Nav Long-form 데스크톱에서 좌측에 고정 섹션 내비게이션(Technology/Business/Achievements) 추가, 핵심 수치는 풀쿼트 카드로 강조. 장점: 페이지 길어져도 탐색 편리, 에디토리얼한 느낌 / 단점: 모바일에서는 내비게이션 이점이 줄어듦
