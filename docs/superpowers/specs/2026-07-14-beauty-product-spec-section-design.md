# Beauty 도메인 페이지 — 제품 스펙 섹션 추가

## 배경
`domains-beauty.html`에 소형 휴대용 피부 측정기(비접촉 광학 센서 디바이스)의 제품 스펙을 소개하는
섹션이 없었다. 사용자가 제공한 목업 이미지(제품 사진 + 5가지 특징 카드)를 기반으로 신규 섹션을 추가한다.

## 배치
`TECHNOLOGY` 섹션과 `BUSINESS MODEL & CUSTOMERS` 섹션 사이에 새 섹션을 삽입한다.
기술 설명 직후 구체적인 제품 스펙으로 이어지고, 이후 비즈니스/고객 설명으로 연결되는 흐름.

## 레이아웃
기존 `.domain-tech-split-layout` 2단 패턴을 재사용한다.
- 좌측: eyebrow "PRODUCT SPEC" + heading "소형 휴대용 <b>피부 측정기</b>" + 리드 문장 + 5개 특징 카드(2열 그리드)
- 우측: 제품 사진(회색 휴대용 측정기, 원본 이미지에서 크롭) — `.domain-tech-split-img` 카드 스타일 재사용

## 콘텐츠 (5개 특징 카드)
1. 비접촉 측정 — 피부에 닿지 않아 위생적이고 편리합니다
2. 30초 이내 측정 — 짧은 측정 시간으로 매장·가정 어디서나 빠르게 사용합니다
3. 휴대용 소형 기기 — 가볍고 컴팩트한 디자인으로 이동과 설치가 쉽습니다
4. 약 30만원 가격 경쟁력 — 도입 부담을 낮춘 합리적인 가격대입니다
5. 높은 정확도 — 정량 데이터 기반으로 신뢰도 높은 측정 결과를 제공합니다

아이콘은 외부 라이브러리 없이 인라인 SVG(손/비접촉, 스톱워치, 기기, 가격표, 타겟)로 구성한다.

## 이미지 에셋
공유된 원본 이미지에서 제품 사진 부분만 크롭하여 `assets/domain-beauty-device.png`로 저장한다.
전체 목업 스크린샷이 아닌, 제품 단독 사진만 사용한다.

## 스타일링
- 새 카드 컴포넌트는 기존 `.domain-stat-card`의 시각적 톤(배경 `#fffdf9`, 라운드, 그림자)을 따르되
  아이콘 배지가 추가된 별도 클래스(`.domain-feature-card` 등)로 구현한다.
- 기존 `reveal-fade` 스크롤 애니메이션 패턴을 유지한다.
- 반응형: 900px 이하에서 `.domain-tech-split-layout`과 동일하게 `flex-direction: column-reverse`로 전환.

## 범위
이 작업은 `domains-beauty.html`, `style.css`, 신규 이미지 에셋(`assets/domain-beauty-device.png`)에 한정된다.
다른 도메인 페이지(agriculture/resource/bio)는 변경하지 않는다.
