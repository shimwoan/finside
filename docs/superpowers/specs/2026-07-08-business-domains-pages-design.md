# 사업 분야 상세 페이지 설계

## 배경

`index.html`의 `#domains` 섹션은 뷰티/농산물/바이오공정/자원순환 4개 사업 분야를 탭 전환 UI로 요약(태그/타이틀/설명/키워드칩)만 보여주고 있다. 이번 작업은 상단 nav에 "사업 분야" 드롭다운 메뉴를 추가하고, 4개 하위 항목이 각각 독립된 상세 페이지로 연결되도록 하는 것이다. 각 페이지는 홈페이지 요약을 확장해, `ref/` 폴더의 IR/사업계획 PPTX 자료에 근거한 기술 설명·비즈니스 모델·성과(특허/TRL/파트너)를 담는다.

## 참조 자료 요약 (ref/ pptx 추출)

리서치 에이전트가 5개 PPTX(`FINSIDE_IR_vFF`, `01. IP스타과학자`, `02. TeX-Corps`, `03. 충북인공지능산업`, `C-LOVE NEXT BRIDGE`)에서 도메인별 내용을 추출했다. 4개 도메인 중 **자원순환은 전용 자료가 없고 IP스타 자료 내 3개 병렬 트랙 중 하나로만 등장** — TRL 진행 상황 외에 매출/특허 수치, 캐치프레이즈가 존재하지 않는다. 이 페이지는 다른 3개보다 명시적으로 더 짧고 개괄적으로 구성하며, 없는 수치를 채워 넣지 않는다.

**Beauty**: LWIR 기반 비접촉 피부 진단(수분·유분·탄력), OSMU 원천기술의 스핀오프. B2B2C — 화장품 소매점(올리브영급 최대 1,300개 매장), 피부관리실(전국 35,000개 중 목표 10%), 스킨케어 기업 협업(에이피알/세라젬/달바). B2C 디바이스 ₩300,000 + 구독 ₩30,000~50,000/월. TAM $19.79B(Grand View Research, CAGR 17.9%). 특허 국내 8건+PCT 2건(회사 전체 30건 중). 경쟁제품 비교(IMate, VCARE 등 대비 정확도 우위).

**Agriculture**: V자형 레일 기반 모듈형 선별 플랫폼(당도/수분/경도/착색/중량 측정 모듈 조합), 농가형(Compact)·센터형(Industrial) 2종. 고객: 농가 + 산지유통센터/APC(현재 외산 장비 지배 시장). 모듈 단위 라이센싱 + SaaS(AI 품질예측). TRL 4(2024)→6(2025 시제품)→7(2026 목표). 충북도 사업 3년/90억원 규모. 파트너: 진영산업, 한성티앤아이, 한아, 이듬, 에이오팜. 매출 로드맵 2028년 20억→2030년 120억.

**Bio & Process**: "FBE 시스템" — 비접촉 LWIR 열화상 기반 실시간 함수율(수분) 분석, 이동 컨베이어 위에서 무중단 계측. 축분→바이오차 전환 공정 대상. 기존 방식(전기전도도, 건조감량법, 열풍건조기) 대비 유일하게 "실시간+무제한 샘플+높은 정확도+현장적합" 모두 충족(비교표 재사용). 고객: B2B — 바이오차 생산기업, 장비 통합사. TRL 6(2024-25)→필드실증(2026)→7(2027). 최대 파트너 해표산업(누적 기술이전 계약). 도메인 중 유일하게 강한 캐치프레이즈 보유: "보이지 않는 공정 품질을 데이터로 측정하는 기술."

**Resource Circulation**: 초분광+가시광 융합 폐플라스틱 재질 선별. TRL 6(2025 데이터수집)→7(2026, 폐배터리 해체·재활용 필드실험 확장 예정)→2027 실증/사업화. 파트너: 위드위(폐플라스틱 분류 One-Stop 시스템 공동개발). 매출/특허 수치 없음 — 페이지에서 억지로 만들지 않음.

## Nav 변경

- 현재 `partials/header.js`(실제 로딩되는 파일 — `nav-scroll.js`는 어느 HTML에서도 include되지 않는 미사용 중복 파일이므로 이번 작업에서 건드리지 않음)의 "Technology"(`#domains` 앵커) 링크를 제거하고, 그 자리에 "사업 분야" 드롭다운으로 교체.
- 드롭다운 하위 4개 항목: 뷰티 · 농산물 · 바이오공정 · 자원순환 → 각각 `domains-beauty.html`, `domains-agriculture.html`, `domains-bio.html`, `domains-resource.html`로 연결.
- 데스크톱: CSS `:hover`/`:focus-within` 기반으로 서브메뉴 노출(기존 nav가 이미 순수 CSS 기반이므로 동일한 패턴 유지, 별도 JS 상태 불필요).
- 모바일(터치, hover 없음): 상위 "사업 분야" 링크를 탭하면 `#domains`(현재 index.html에만 존재하는 앵커이므로, 다른 페이지에서는 `index.html#domains`)로 이동시키고, 서브메뉴는 별도 토글 없이 nav 자체 너비가 좁아지는 현재 사이트의 480px 축소 패턴(폰트/gap만 축소, 별도 햄버거 없음)을 그대로 따른다 — 즉 모바일에서는 드롭다운 대신 상위 링크를 홈 도메인 섹션으로 보내고, 4개 상세 페이지는 홈 `#domains` 패널의 "자세히 보기" 링크를 통해 접근하는 경로도 함께 제공한다.
- `about.html`처럼 현재 페이지가 4개 도메인 페이지 중 하나일 때 nav에서 해당 드롭다운 항목에 active 스타일 적용. 현재 `header.js`의 링크 배열은 `active: true` 플래그를 항목 단위로만 지원하므로(현재는 About Us 항목에만 사용), "사업 분야" 드롭다운 하위 서브링크 배열에도 동일한 `active` 플래그 지원을 추가해 해당 `NAV_PAGE` 값과 일치하는 서브링크에 active 클래스가 붙도록 로직을 확장한다. `NAV_PAGE` 값은 페이지별로 `domains-beauty`/`domains-agriculture`/`domains-bio`/`domains-resource`를 사용하며, 기존 `page === 'index'` 분기 로직은 이 값들을 모두 "index가 아닌 페이지"로 취급하므로 별도 분기 추가 없이 기존 구조와 호환된다.

## 페이지 구조 (4개 파일 공통 템플릿)

`about.html`과 동일한 기술적 관례를 따른다: `<script>window.NAV_PAGE = 'domains-beauty';</script>`(각 페이지별 고유값) → `partials/header.js` → 콘텐츠 섹션들 → `partials/footer.js` → reveal-fade IntersectionObserver 스크립트. 배경/텍스트 컬러, 폰트, `.eyebrow`/`.heading`/`.section-inner`/`.reveal-fade` 클래스는 `style.css`에 정의된 것을 그대로 재사용(about.html과 동일한 라이트 크림 테마).

**공통 섹션 순서**:

1. **Hero** — eyebrow(도메인 태그, 예: "BEAUTY") + title(홈페이지 `DATA` 객체의 title 재사용) + lead(기존 desc 재사용 또는 소폭 확장) + hero 이미지(기존 `assets/domain-panel-*.png` 재사용, 새 이미지 제작 없음)
2. **Technology** — 리서치로 추출한 기술 원리 상세 설명. Beauty/Bio는 경쟁사·대안 비교표를 표로 재현(Bio의 FBE 비교표, Beauty의 경쟁제품 비교). Agriculture는 모듈 구성 리스트, Resource는 기술 단계(초분광 진단→AI 선별→다중센서) 설명.
3. **Business Model & Customers** — B2B/B2C 고객군, 명명된 파트너사, 가격/시장 규모(있는 경우만). Resource는 파트너(위드위)와 고객군만 간략히 서술.
4. **Achievements** — TRL 진행 단계, 특허, 매출 로드맵, 정부과제 규모 등. **Resource Circulation 페이지에는 이 섹션을 넣지 않는다** — 근거 수치가 없기 때문.
5. **Footer CTA 스트립** — "다른 사업 분야 보기" 형태로 나머지 3개 도메인 페이지 링크 + `index.html#domains`로 돌아가는 링크.

## 홈페이지(index.html) 연동

- `#domains`의 각 `.domain-panel-text` 블록(태그/타이틀/설명/칩 아래)에 "자세히 보기 →" 링크를 추가, 현재 활성화된 탭(`activate(key)`가 바꾸는 key)에 맞는 도메인 페이지로 연결. 탭 전환 시 이 링크의 `href`도 함께 갱신되도록 기존 `activate()` 함수에 한 줄 추가.

## 스코프 제외

- 자원순환 페이지에 존재하지 않는 매출/특허/캐치프레이즈를 만들어 채우는 것
- 새 사진·일러스트 제작 (기존 `assets/domain-panel-*.png`, `domain-*.png` 아이콘만 재사용)
- 모바일 전용 햄버거 메뉴 신설 (현재 사이트에 없는 패턴이므로 이번 작업 범위 밖 — 480px 폭 축소 방식 유지)
- `partials/nav-scroll.js` 정리/삭제 (미사용 파일이나 이번 작업과 무관하므로 건드리지 않음)
