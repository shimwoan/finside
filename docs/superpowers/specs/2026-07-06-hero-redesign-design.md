# Hero 섹션 리디자인 — 설계 스펙

날짜: 2026-07-06

## 배경 / 목적

기존 hero 섹션은 다크 배경 + 3D 분자 애니메이션 + 좌측 텍스트 단독 구성으로, 회사의 핵심 사업(AI 비접촉 피부 진단 데이터 플랫폼)을 추상적으로만 표현하고 있다. 참고 이미지(실사 사진 기반 목업)를 바탕으로, 실제 제품 사용 장면과 데이터 시각화를 결합한 라이트 테마 hero로 전면 교체한다.

## 참고 자산

- `assets/hero-person-device.png` — 참고 목업에서 크롭한 실사 이미지 (여성이 흰색 원통형 디바이스를 뺨에 대고 있는 옆모습, 뺨 위에 파란 스캔 그리드 정적 이펙트 포함). 배경 텍스트/카드 조각은 화이트로 패치 완료.

## 레이아웃 구조

- 좌측 (~45%): 텍스트 콘텐츠 (eyebrow, 헤드라인, 서브카피, CTA 1개)
- 우측 (~55%): 실사 이미지 + 라이브 스캔 그리드 오버레이 캔버스, 우측 하단에 "주요 지표" 카드 플로팅
- 배경: 다크(`--bg: #0e0e0e`) → 라이트(오프화이트 계열, 예: `#fafafa` ~ `#ffffff`)로 전환. 기존 `#hero::before`의 다크 radial glow 제거.
- 네비게이션: 라이트 테마로 전환 — 로고/링크 텍스트를 다크 톤으로, `nav-links` 색상 및 `nav.scrolled` 배경(blur) 조정. 우측에 블루 "문의하기" CTA 버튼 추가.
- 기존 3D 분자 캔버스(`#scene`, `buildParticles`/molecule 애니메이션 전체)는 hero에서 제거.
- 파트너 로고 스트립은 이번 스코프에서 제외 (hero를 단순하게 유지하기 위함). 필요 시 별도 후속 작업으로 다룬다.

## 텍스트 콘텐츠

- Eyebrow: "측정 · 진단 · 데이터 플랫폼" — 기존 `.hero-label` 스타일 재사용, 라이트 테마 색상(다크 톤)으로 조정.
- 헤드라인: "정확한 측정 데이터 기반으로 더 나은 결정을 만듭니다" — "데이터"만 블루(`#2f6bff` 계열) 강조. 기존 `.reveal-block`/`.reveal-inner` 한 줄씩 올라오는 애니메이션 그대로 재사용.
- 서브카피: "비접촉 방식으로 피부 데이터를 정밀하게 측정하고,<br>축적된 데이터를 기반으로 신뢰할 수 있는 인사이트를 제공합니다"
- CTA: 버튼 1개로 단순화 — "솔루션 자세히 보기 →" (블루 배경, 흰 텍스트). 기존 `.btn-ghost`("IR 자료 보기")는 제거.
- 하단 stats bar(`.hero-stats`, "뷰티·농산물 선별 / 분석 정확도 98%")는 제거 — "주요 지표" 카드가 동일 역할을 대체하므로 중복.

## 이미지 & 스캔 그리드 이펙트

- `hero-person-device.png`를 우측에 배치. 높이 기준 반응형 스케일: `height: clamp(500px, 75vh, 780px)`.
- 이미지 하단은 `mask-image: linear-gradient(to bottom, black 85%, transparent)`로 살짝 페이드 처리하여 화이트 배경과 자연스럽게 이어지게 한다.
- 기존 3D 분자 캔버스 코드(JS의 `buildParticles`, molecule 관련 렌더 루프 전체)를 제거하고, 대신 이미지 위 뺨 위치에 겹치는 새 오버레이 캔버스를 추가한다.
  - 방사형으로 확산되는 도트/라인 그리드 패턴 (이미지 속 정적 그리드와 유사한 위치·스케일에 맞춰 좌표 조정)
  - 은은한 pulse 애니메이션 (스케일/투명도, 2~3초 주기)
  - 색상: 블루 계열(`#4a9eff` ~ `#2f6bff`), 화이트 배경 위에서 튀지 않도록 opacity 조절
  - "피부층 깊이 탐지" 느낌을 위해 2~3개의 depth layer가 서로 다른 속도로 pulse하도록 구성. 그로테스크한 디테일(모공, 혈관 등 사실적 피부 텍스처) 없이 기하학적 패턴으로만 표현.

## 주요 지표 카드

- 위치: 이미지 우측 하단에 겹쳐서 플로팅 (참고 이미지 카드 포지션과 동일). 화이트 배경 + 옅은 box-shadow.
- 항목 6개, 각각 얇은 바 그래프:
  - 수분 76
  - 유분 65
  - 모공 72
  - 탄력 68
  - 멜라닌 58
  - 피부결 81
- scroll-reveal 시 0 → 목표치로 바 애니메이션 (기존 `data-target` 카운터 패턴 재사용).
- **수분(76) 항목만 빨간색**으로 강조 표시 — "수분 부족"을 시각적으로 부각시키는 것이 원 요구사항.

## 스코프 제외 (Out of scope)

- 파트너 로고 스트립 추가
- "종합 피부 점수" / "피부 분석 결과" 카드 (원 요청에 따라 제외, "주요 지표" 카드만 사용)
- 다른 섹션(IP 확보 등) 변경 없음 — hero 섹션(`#hero`)과 관련 nav 스타일에 한정

## 기술 노트

- 기존 CSS 커스텀 프로퍼티(`--bg`, `--text` 등)는 hero 스코프 내에서만 라이트 테마 오버라이드하거나, 전역 테마를 라이트로 바꾸고 다른 섹션들의 다크 스타일은 섹션별 로컬 오버라이드로 유지하는 방식 중 구현 단계에서 선택.
- `scroll-snap-type: y mandatory` 및 기존 reveal-on-scroll(IntersectionObserver) 패턴은 유지.
