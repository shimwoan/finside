# Resource Circulation 페이지 — 선별 시스템 장비 섹션 추가

## 배경

`domains-bio.html`에는 "FBE 시스템" 섹션이 있다 — 장비 사진과 기능 아이콘 그리드를
좌우로 배치한 `sort-platform-*` 스타일 섹션. `domains-resource.html`에는 현재 이
장비 섹션이 없고, TECHNOLOGY/BUSINESS MODEL 텍스트 섹션만 존재한다.

`ref/` 자료(01. 1단계 IP스타과학자 결과 및 2단계 사업계획 발표자료) 조사 결과,
자원순환 도메인의 핵심 기술은 **초분광·가시광·열화상 융합 비파괴 선별 시스템**이며
다음과 같이 문서화되어 있다:

- 파트너사 **위드위(WithWe)**: 폐플라스틱 분류 One-Stop 시스템 구축 기업으로, 본
  연구자의 기술을 도입해 비파괴 플라스틱 선별 시스템을 구축 중
- 기술 구성: 초분광(hyperspectral) + 가시광 + 열화상 센서 융합, 고정 장치·조명·
  촬영각도 조절 구조
- TRL 로드맵: 2024 TRL6(AI 선별 알고리즘 고도화, 폐배터리 해체·재활용 필드 실험)
  → 2025 TRL7(폐플라스틱 품질 진단 원천기술) → 2026(저비용 대안 시스템 개발, 초분광·
  가시광 융합 검증) → 2027(다중 스펙트럼 자율지능형 AI 선별시스템)
- 시장 니즈: 기존 초분광 전용 고비용 장비 대비 저렴한 대안이 필요한 시장

사용자가 제공한 이미지는 `assets/fbe-system-device.png` (bio 페이지에서 이미 사용
중인 동일 이미지)이며, 사용자 확인 결과 이 페이지에도 동일 이미지를 그대로 재사용하기로
결정했다. (참고: `assets/sort-platform-device.png`라는 컨베이어/선별 장비로 보이는
별도 이미지가 자산 폴더에 있으나, 사용자가 명시적으로 `fbe-system-device.png` 사용을
선택함.)

## 범위

- **포함**: `domains-resource.html`의 기존 "TECHNOLOGY" 텍스트 섹션을 `sort-platform-*`
  레이아웃(이미지 + 헤딩/부제/본문 + 6개 기능 아이콘 그리드)으로 교체
- **제외**: "BUSINESS MODEL & CUSTOMERS" 텍스트 섹션 — 현재 그대로 유지 (범위 밖)

## 설계

### 배치

```
히어로 섹션 (기존, 변경 없음)
  ↓
[교체] TECHNOLOGY 섹션 — 텍스트 전용 → sort-platform-* 이미지+그리드 스타일
  ↓
BUSINESS MODEL & CUSTOMERS 텍스트 섹션 (기존, 변경 없음)
```

### 신규 섹션 내용

`domains-bio.html`의 FBE 시스템 섹션과 동일한 마크업 구조
(`sort-platform-section` / `sort-platform-layout` / `sort-platform-visual` /
`sort-platform-content` / `sort-platform-grid`)를 재사용한다. 기존 CSS를 그대로
쓰므로 스타일 변경은 없다.

- **배경색**: 기존 TECHNOLOGY 섹션의 `background: #faf8f4;` 유지
- **좌측 이미지**: `assets/fbe-system-device.png`
  - alt: `"폐플라스틱 초분광·가시광·열화상 융합 선별 시스템"`
- **우측 제목**: `초분광·가시광·열화상 <b>융합 선별</b>`
- **Subhead**: `비파괴·비접촉 방식의 폐플라스틱 다중센서 AI 선별 시스템`
- **바디 텍스트** (기존 TECHNOLOGY 본문 재구성, ref 자료 기반):
  > 초분광(hyperspectral)과 가시광·열화상 센서를 융합해 폐플라스틱의 재질 성분을
  > 비접촉 방식으로 진단하는 원천기술(TRL 6, 2024~25)을 시작으로, AI 선별 알고리즘을
  > 고도화(TRL 7, 2026 목표)해 폐배터리 해체·재활용 필드 실험까지 적용 범위를 넓히고,
  > 2027년에는 다중 스펙트럼 자율지능형 AI 선별시스템으로 발전시키는 로드맵을 갖고
  > 있습니다. 시스템은 가시광·열화상 센서와 고정 장치·조명·촬영각도 조절 구조로
  > 구성됩니다.
- **기능 아이콘 그리드 (6종)**, 기존 SVG 아이콘 스타일(stroke, `currentColor`) 유지,
  bio 페이지와 겹치지 않는 아이콘 선택:
  1. 초분광 재질 성분 분석
  2. 가시광·열화상 융합 센싱
  3. 비파괴·비접촉 선별
  4. AI 선별 알고리즘 고도화
  5. 고정 장치·조명·각도 조절
  6. 폐배터리 해체·재활용 확장

## 테스트

- 브라우저에서 `domains-resource.html` 열어 레이아웃 확인 (교체된 섹션이 히어로와
  BUSINESS MODEL 섹션 사이에 올바르게 배치되는지)
- 반응형 확인: `sort-platform-layout`은 기존 CSS 미디어쿼리로 모바일에서 세로 스택
  되므로 별도 CSS 작업 불필요 — 시각적으로 확인만
- reveal-fade 애니메이션 동작 확인 (기존 IntersectionObserver 스크립트 재사용)
