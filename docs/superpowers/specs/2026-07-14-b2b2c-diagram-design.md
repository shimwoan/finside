# B2B2C 피부 데이터 다이어그램 — domains-beauty.html

## 배경

`domains-beauty.html`의 "BUSINESS MODEL & CUSTOMERS" 섹션(현재 라인 56-70)은 텍스트 단락만으로
B2B/B2C 고객 정보를 나열하고 있다. 사용자가 제공한 레퍼런스 인포그래픽(IR 자료 스타일)처럼
좌측 헤딩+통계, 중앙 B2B 카드 — 디바이스/앱 비주얼 — B2C 카드로 이어지는 구조화된 다이어그램으로
교체한다.

## 목표

- 기존 텍스트 정보(B2B 파트너 3종, B2C 모델 3종, 목표 수치)를 시각적 다이어그램으로 재구성
- Finside 기존 디자인 토큰(크림/골드 팔레트, `.domain-stat-card` 스타일)과 일관되게
- 새 이미지 에셋 추가 없이 기존 `hero-person-device.png`를 크롭 재사용 + CSS로 폰 UI 목업 제작
- 900px 이하에서 세로 스택으로 반응형 대응

## 범위

- 대상 파일: `domains-beauty.html` (섹션 마크업 교체), `style.css` (신규 클래스 추가)
- 다른 도메인 페이지(`domains-bio.html`, `domains-resource.html` 등)는 이번 변경에 포함하지 않음
- 신규 이미지 에셋 생성 없음 (기존 `assets/hero-person-device.png` 크롭 재사용)

## 레이아웃

### 데스크톱 (>900px)

```
[eyebrow: BUSINESS MODEL & CUSTOMERS]
[heading: B2B2C로 연결되는 피부 데이터]
[intro 문장]
[stat 블록 2개: 파트너 네트워크 목표 1,300+ / 피부관리실 목표 3,500+]

┌─────────────┐  ···  ┌──────────────┐  ···  ┌─────────────┐
│  B2B 카드    │       │ 디바이스+폰   │       │  B2C 카드    │
│ (3행)       │       │  비주얼       │       │  (3행)      │
└─────────────┘       └──────────────┘       └─────────────┘

[footnote: ※ 수치는 2024년 기준 목표치...]
```

- 상단 헤딩/통계 블록은 전체 너비, 하단 다이어그램 행(B2B 카드 / 디바이스+폰 / B2C 카드)은
  flex row로 배치
- B2B/B2C 카드와 중앙 비주얼 사이는 점선 커넥터로 연결

### 모바일 (≤900px)

세로 스택: intro/stats → B2B 카드 → 디바이스+폰 비주얼 → B2C 카드. 커넥터는 수직 점선으로 회전.

## 컴포넌트 상세

### 1. Intro 블록 (`.biz-flow-intro`)
- eyebrow, heading(기존 텍스트 유지), intro 문장(레퍼런스 이미지 문구 활용)
- `.biz-flow-stats`: 아이콘 + 라벨 + 굵은 숫자 형태의 stat 2개
  - 파트너 네트워크 목표 **1,300+** 소매점 매장
  - 피부관리실 목표 **3,500+** 전국 피부관리실

### 2. B2B 카드 (`.biz-flow-card`)
- 상단 pill 라벨 "B2B"
- 타이틀 "전문 파트너"
- 3개 row, 각 row는 아이콘 + 소제목 + 상세 설명:
  - 화장품 소매점 — 약 1,300개 매장, 확대 목표
  - 피부관리실 — 전국 약 35,000개 중 10% 목표(약 3,500개)
  - 스킨케어 기업·브랜드 — 에이피알·세라젬·달바 등 공동 마케팅 및 기술 라이선싱

### 3. 중앙 비주얼 (`.biz-flow-visual`)
- 좌: 디바이스 이미지 — `hero-person-device.png`를 CSS `object-fit`/`object-position`으로
  디바이스 부분만 크롭하여 표시 (라벨: "휴대용 피부 측정 디바이스")
- 중: "+" 구분자
- 우: 폰 앱 목업 (라벨: "데이터 플랫폼 / 앱") — 신규 이미지 없이 HTML/CSS로 제작
  - 폰 프레임(둥근 사각형 테두리)
  - "피부 분석 결과" 텍스트
  - 원형 점수 인디케이터: **85** (border-based ring, SVG/conic-gradient)
  - 4개 지표: 수분 82 / 유분 68 / 탄력 87 / 진정 90
  - "피부 변화 추이" 미니 트렌드 라인 (간단한 SVG polyline)

### 4. B2C 카드 (`.biz-flow-card`)
- 상단 pill 라벨 "B2C"
- 타이틀 "최종 소비자"
- 3개 row:
  - 디바이스 구매 — 30만원
  - 월 구독 — 3~5만원
  - 시장 규모 — TAM $19.79B · SAM 약 $8.1B (Grand View Research · CAGR 17.9%)

### 5. Footnote
- "※ 수치는 2024년 기준 목표치이며, 시장 데이터는 Grand View Research 기준입니다."

## 아이콘

인라인 SVG 라인 아이콘 사용 (신규 이미지 파일 생성하지 않음): 상점, 얼굴, 건물, 쇼핑백, 카드, 막대그래프.
심플한 outline 스타일로 골드 톤(`#a68a6d`) 스트로크.

## 비고

  UI 데모 목적
- JS/백엔드 변경 없음, 순수 HTML+CSS 추가
