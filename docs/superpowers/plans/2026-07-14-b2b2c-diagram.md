# B2B2C 피부 데이터 다이어그램 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `domains-beauty.html`의 "BUSINESS MODEL & CUSTOMERS" 섹션을 텍스트 단락에서, 좌측 헤딩/통계 +
B2B 카드 — 디바이스/앱 비주얼 — B2C 카드로 이어지는 구조화된 인포그래픽 다이어그램으로 교체한다.

**Architecture:** 순수 HTML + CSS 변경. 새 JS/이미지 에셋 없음. 기존 `assets/hero-person-device.png`를
CSS `object-fit`/`object-position`으로 크롭 재사용. 폰 앱 UI는 HTML/CSS로 직접 제작(원형 점수 링은
`conic-gradient`, 추이 그래프는 인라인 SVG polyline). 아이콘은 기존 `.domain-feature-icon` 패턴(원형
배지 + 20px stroke SVG)을 재사용.

**Tech Stack:** 정적 HTML, CSS (빌드 도구 없음). 이 저장소에는 테스트/빌드 파이프라인이 없으므로 각
태스크의 검증은 브라우저 스크린샷 확인으로 진행한다.

## Global Constraints

- 대상 파일: `domains-beauty.html` (라인 183-197 섹션 교체), `style.css` (신규 클래스 추가)

- 색상 토큰: 카드 배경 `#fffdf9`, 카드 그림자 `0 1px 0 #2a251f0f, 0 20px 40px -24px #2a251f1f`,
